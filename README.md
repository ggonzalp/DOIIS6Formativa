# SPEEDFAST

La actividad formativa de esta semana consiste en crear la Interfaz Gráfica del Usuario del programa diseñado para SpeedFast, con el objetivo de  
permitir que las operaciones básicas se realicen de manera intuitiva y organizada para el usuario.

## Descripción

El programa consiste en una interfaz gráfica sencilla que posee tres botones, el primero para registrar el pedido que abre el formulario de registro
que incluye la selección del tipo de pedido, la prioridad del mismo y su validación; el segundo botón muestra el historial de pedidos
registrados y, por último, el botón de asignar repartidor el que, en un futuro, podría ampliarse para incluir una cuarta ventana de registro para 
repartidores y validaciones correspondientes con mayor rigurosidad. 


## Ejecución

1° Clonar el repositorio: https://github.com/ggonzalp/DOIIS6Formativa

2° Abrir el proyecto en IntelliJ IDEA

3° Ejecutar la clase principal: src/ui/Main.java

4° El programa cargará automáticamente una ventana con los tres botones mencionados anteriormente.
